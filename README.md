## Daniel Riccio

Hey, I'm Daniel, a software engineer in Colombia. I spend most of my time building AI agents and the tools around them, and it's the most fun I've had building software.

Lately I've been working on [Lamp](https://github.com/lampdotdev/Lamp), where you can make and remix apps by describing what you want, and contributing to [OpenClaw](https://github.com/openclaw/openclaw). I've also worked on [Roomote](https://github.com/RooCodeInc/Roomote), a cloud coding agent you can self-host.

I'm into agents that can use computers, keep track of their work, and hold up outside a demo. A lot of my work is making that reliable, from tool permissions and memory to testing what actually happens on screen.

I also built [lampvm](https://github.com/RooCodeInc/lampvm): isolated macOS VMs for agents to test apps.
